# 文体规则 · Genre Rules

> 先判文体，再分段。**分段错了，后面全错**——逐节平均切是最大的失败模式。

## 判定表

| 文体 | 书卷 | 分段单位 | 结构图形式 |
|---|---|---|---|
| 叙事 | 创–斯、福音书、使徒行传 | 一个场景 / 一个事件 | 场景链 + 转折点 |
| 书信 | 罗–犹 | 一个论证单元（连接词为界） | 论证流：因为→所以 |
| 诗歌 | 诗、歌、哀歌 | 一个诗段 / 一组平行句 | 意象群 + 情绪弧 |
| 律法 | 出 20–40、利、申 | 一个条例组 / 一个主题群 | 条例分类树 |
| 先知·启示 | 赛–玛、启 | 一个神谕 / 一个异象 | 审判—应许—应验 |

## 1. 叙事

**分段**：按「谁在哪里做了什么、冲突在哪转折」切，不按节切。
一个场景典型 3–8 节；一章常见 4–8 段。

**结构图**：`地点 → 事件 → 反应 → 转折`。标出「谁在场、谁说话、谁缺席」。

**必答**：
- 这一章的冲突是什么？谁跟谁冲突？
- 主角做了什么选择？代价是什么？
- 叙述者重复了哪个词？（马可的「立刻」、路加的「赞美」）

**坑**：
- 把历史记载当道德命令（描述性 ≠ 规范性）
- 给人物编心理活动（「彼得心里想…」经文没写就不写）
- 把比喻的点全部寓意化

## 2. 书信

**分段**：找连接词——`因为 / 所以 / 既然 / 因此 / 但 / 况且`。一个论证单元常跨 5–15 节。

**结构图**：`前提 → 推论 → 例证 → 应用`，标出「直说」和「推论」的分界。

**必答**：
- 保罗在回答什么问题？（多半是教会的具体问题）
- 这段的「因此」承接到哪里？
- 哪些是命令式，哪些是陈述式？

**坑**：
- 把一句抽出来当独立金句（罗马书 8:28 脱离 8:18–27 的苦难语境）
- 忽略「你们」是复数（教会性，不只是个人）
- 把「称义」和「成圣」混为一谈

## 3. 诗歌

**分段**：按诗段（stanza），不是按节。希伯来诗歌靠**平行体**推进：同义、反义、综合。

**结构图**：`意象 → 情绪 → 转折 → 呼求/赞美`。

**必答**：
- 平行句在重复什么、推进什么？
- 诗人的情绪从哪里到哪里？
- 有没有「转调」（如诗篇 13 从哀到信靠）？

**坑**：
- 把意象当密码本（山=国家、水=苦难，一律套）
- 忽略标题与「细拉」
- 用一节安慰人，忽略整篇的哀诉

## 4. 律法

**分段**：按条例组（祭祀、洁净、民事、节期、道德）。

**结构图**：`类别 → 条例 → 目的 → 指向`。

**必答**：
- 这条属于礼仪律、民事律，还是道德律？
- 它保护谁？（弱者、外人、奴隶、牲畜）
- 它在基督里如何被成全或废止？

**坑**：
- 直接把礼仪律套到今天（不吃血、不穿混纺）
- 把民事律当国家立法蓝图
- 十字架后仍要求守全律法

## 5. 先知 · 启示文学

**分段**：按神谕（「耶和华的话临到我说」）或异象（「我看见」）。

**结构图**：`历史处境 → 指控 → 审判 → 余民应许`。

**必答**：
- 先知在对哪个年代、哪个国家说话？
- 审判是针对谁？应许是给谁？
- 哪些已经应验，哪些等待再来？

**坑**：
- 把象征数字直接算成年代（七十个七、1260 天）
- 把启示录当新闻解码器
- 忽略「已然 / 未然」

---

## 判断口令（写之前先答三句）

1. 这一章**是什么文体**？（一句话）
2. 按这个文体，**该切几段**、每段边界在哪？
3. 这一章**最容易被读错的一处**是什么？

答不出第三句，说明还没读懂，回去读三遍。

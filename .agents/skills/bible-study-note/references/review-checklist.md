## 审查报告模板

写到 `reviews/<id>.txt`：

```
<书卷> 第 <n> 章 · 审查报告
生成时间：YYYY-MM-DD
脚本结果：P0 x / P1 y

【P0】
A04 ✗ 缺 2:13；1..28 中 13 未出现 → 在 SEG 05 补
B05 ✗ 应用「要多读经」不可执行 → 改为「周一至周五 7:00 读可 2 章一遍」

【P1】
C01 bg 1280 字（预算 1600 内）✓
C04 结构表把 2:18-22 与 2:23-28 合并，正文分成两段 → 统一

【结论】
修订后复跑：PASS
```

**报告里不许出现「整体良好」「基本符合」这类无法定位的话。**

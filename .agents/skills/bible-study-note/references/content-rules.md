# 内容规则 · Content Rules

> 模板管「长什么样」，这份文件管「说得对不对」。

## 1. 三级标注怎么用

| 你写的内容 | 标注 | 例子 |
|---|---|---|
| 经文原话、清楚的直接教导 | 不标 / 🟦 | 「耶稣动了慈心，伸手摸他」 |
| 注释传统、背景考据、词义争议 | 🟨 | 「有古卷作『耶稣发怒』」 |
| 你的推论、联想、应用 | 🟧 | 「这预表十字架上的交换」 |

判定方法：**这句话能不能被一节经文直接引用支持？**
不能 → 必须 🟨 或 🟧。拿不准就标 🟧，标多了不丢人，标少了是欺骗。

## 2. 描述性 ≠ 规范性

历史记载「发生了什么」，不等于「你该做什么」。四道检验：

1. **命令检验**：经文有没有用命令式？没有 → 不能写成「神要你做」。
2. **语境检验**：这是给个人的，还是给群体的？是给当时的，还是给历代的？
3. **整本检验**：别处经文是否也这样教导？孤证不立。
4. **基督检验**：这件事在基督里如何被成全？旧约尤其要过这一关。

| 错 | 对 |
|---|---|
| 「基甸用羊毛求印证，所以我们也可以这样求神旨意」 | 「基甸的羊毛是他在软弱中的求证，不是给我们的方法；经文本身没有赞赏这个做法」 |
| 「雅比斯求扩张境界，所以你也要这样祷告」 | 「历代对雅比斯祷告的评价不一，不宜当作祷告公式」 |

## 3. 应用怎么写才算过关

公式：**对象 + 时间 + 动作 + 可验证**。

| 不合格 | 合格 |
|---|---|
| 要多爱弟兄 | 周三晚给老陈打电话，问他父亲手术情况，听他讲十分钟 |
| 要常常祷告 | 下周一到周五，起床后先不看手机，安静十分钟 |
| 要饶恕 | 这周把那件事写下来，写完读一遍，然后决定一次不再重提 |

- 每章 **1 个主行动**（有难度、有代价）+ **2–3 个场景**（职场/家庭/教会/苦难）+ **2 个辅助操练**
- 场景要具体到「周几、谁、说什么」，不要「在生活中」
- 允许写「做不到」：给出「做不到就记下来，下周再来」，比律法式要求更福音

## 4. 禁用句式

| 禁用 | 原因 | 改写 |
|---|---|---|
| 神今天对你说… | 把推论冒充启示 | 这段经文显明… |
| 主要你… | 同上 | 按这节经文，我们可以… |
| 只要相信，就一定会… | 成功神学 | 应许是确定的，时间是神定的 |
| 神绝不会让你… | 与圣经不符（约伯、保罗、耶稣） | 神在苦难中同在 |
| 这就是神的旨意（用于个人决定） | 越界 | 圣经显明的旨意是…；具体决定需分辨 |
| 家人们 / 宝子们 / 绝绝子 | 语气不符 | 直接说 |
| 不得不说 / 说实话 | 空转 | 删 |

## 5. 事实与数字

- **原文词**：只写你确定的。ἀγαπάω / hesed 这类常见词可以，生僻词宁可不写。
- **统计**：「马可用了 41 次 εὐθύς」→ 必须能给出处，否则写「约 40 次」或「反复出现」。
- **年代**：「约公元 65–70 年」可以；「公元 66 年 3 月」不行。
- **地名距离**：写「约 30 公里」可以，写「32.4 公里」不行。
- **拉比文献、考古发现**：写「拉比传统记载」「考古发现一处 1 世纪会堂地基」，不写具体页码除非真查过。
- **注释书**：只写你确实知道的作者与书名（见 `sources.md`），不编页码。

## 6. 分歧怎么处理

**并列 + 标注 + 不裁判**：

> 对这段有三种主要解释：① …；② …；③ …。前两种在福音派内都有支持者，本章笔记不替你下结论。

必须并列的常见议题：预定论与自由意志、洗礼方式、千禧年、被提时间、女性按立、说方言、教会治理。

**例外（必须明确表态）**：基督的神人二性、因信称义、身体复活、三位一体、圣经的权威。这些不是「观点」，是信条。

## 7. 语气

- 对读者：像一个耐心的老师，不像布道家，也不像学术论文
- 少用感叹号；一章最多 2 个
- 用「你」不用「我们大家」
- 引用原文用「」，不用 ""
- 不说教、不煽情、不承诺结果

## 8. 长度纪律

| 模块 | 超预算时的处理 |
|---|---|
| 背景 | 砍细节，留「影响理解这一章」的部分 |
| 分段解释 | 合并重复论点，不是删经文 |
| 重点经文 | 从 5 处减到 3 处，不减步骤 |
| 神学 | 合并同类项，保留 3 个最相关 |
| 应用 | 减场景，不减主行动 |

**总字数纪律**（只算汉字，不含经文以外的标点与拉丁字母）：

| 章型 | 汉字数 |
|---|---|
| 短章（≤25 节） | 5000–8000 |
| 标准章（26–50 节） | 8000–12000 |
| 长章（>50 节） | 10000–15000 |

参考：马可福音 1 章（45 节，10 段）约 11600 字。
超上限 = 没做取舍；低于下限 = 没读进去。`check_note.py` 只做 4500–16000 的兜底，真正的区间靠这条纪律。

## 9. 「与基督的关联」三条检验

写完一条 🟧，问自己：

1. 这是**经文本身**引向基督，还是我硬接的？
2. 能不能用一句话说清「他如何成全」？
3. 如果去掉这条，读者会损失什么？

三问答不上来 → 删掉，不要凑。

## 10. 神学红线（出现即返工）

- 否认基督的神性或人性
- 把救恩说成靠行为 / 靠守律法
- 把圣灵的工作缩减为情绪体验
- 把苦难一律解释为罪的惩罚（约伯记反例）
- 把某一宗派立场写成「圣经明确说」
- 灵意解经：给数字、地名、颜色强行赋义而没有经文依据
- 引用伪经、诺斯底文献当作正典
